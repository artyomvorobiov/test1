# GLIMPSE

Ежедневная браузерная игра на реакцию и внимание. Одна плитка на поле отличается по оттенку — нужно найти и кликнуть её до истечения таймера. 5 раундов в день, сложность растёт (плитки мельче, разница в цвете тоньше, времени меньше), у всех игроков — одна и та же ежедневная задача (сид генерируется от даты UTC).

## Особенности

- **Daily-режим** — одна задача в день на всех, результат сохраняется в `localStorage` (серия побед, статистика).
- **Практика** — неограниченные случайные раунды для тренировки/стрима, не влияет на серию.
- **Шеринг результата** — кнопка копирует в буфер обмена компактную строку с эмодзи-полоской (🟩/🟨/🟥), как в Wordle, без единого текстового ответа — только визуальный результат.
- Никаких зависимостей и сборки: чистые `HTML/CSS/JS`.

## Запуск локально

Это статический сайт — открой `index.html` в браузере или подними любой статический сервер:

```bash
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.

## Структура

- `index.html` — разметка и экраны (интро, игра, результат, модалки).
- `style.css` — тёмная тема, стекло-карточки, анимации.
- `game.js` — вся логика: сидированный генератор, раунды, таймер, статистика, шеринг.

## Деплой
